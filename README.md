# 법률–조례 연결 확인기 · 법률네트워크

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)

> **법령명 · 지자체 · 인증키만 넣으면, 그 법률에 연결된 우리 기관 조례를 찾아 표와 네트워크 그래프로 보여 주는 데스크톱 GUI.**

법제처 **국가법령정보 공동활용 OPEN API**(XML)를 사용합니다.
「공무원을 위한 AI 활용」 7-5장 *‘나를 인용하는 법 찾기’* 의 개념을 도구로 옮긴 것입니다.

---

## 🤔 왜 만들었나

| | |
|---|---|
| **문제 (Why)** | 법령 하나가 개정되면 그 법을 근거로 한 우리 조례·규칙도 따라 고쳐야 하는데, **“어떤 조례가 그 법에 얽혀 있는지” 알기가 어렵다.** 일일이 조례를 열어 확인해야 하고, 빠뜨리면 시행 후 정비를 통째로 다시 돌린다. |
| **방법 (How)** | 법률 MCP(법제처 OPEN API)를 활용해 **복잡한 검색 없이 자동 조회**. 본문 원문을 대조해 진짜 인용만 추리고, 이름이 바뀐 법은 **옛 이름까지 함께** 찾는다. |
| **결과 (What)** | **법령을 입력하면, 그 법에 연결된 우리 기관 조례가 나온다.** (표 + 네트워크 그래프 + 정비 대상 ⚠ 표시) |
| **효과 (So what)** | **법령 개정에 따른 조례 정비의 속도와 진척을 관리**할 수 있다. 입법예고·정비계획 단계에서 대상 조례를 한눈에, 누락 없이. |

> **실제 사례** — `지능정보화 기본법`(옛 이름 `국가정보화 기본법`)으로 조회하면,
> 전라남도 강진군 ‘지역정보화촉진 조례’처럼 **아직 옛 이름을 인용하는 조례**까지 잡아내
> `⚠ 정비 대상`으로 표시합니다. *현행명으로만 검색했다면 빠뜨렸을 조례입니다.*

---

## ✨ 주요 기능

- **옛 법령명 자동 확장** — 제명변경된 법은 `이전법령명`을 자동으로 가져와 현행명과 함께 검색
- **본문 원문 검증(CoVe)** — 검색 결과를 본문과 대조해 ‘근거 / 인용 / 관련’으로 분류(검색 노이즈 제거)
- **네트워크 그래프** — 법률을 중심으로 조례들이 어떻게 걸려 있는지 시각화
- **정비 대상 식별** — 옛 명칭을 인용하는 조례를 ⚠ 로 집어내고 건수로 집계
- **개정안 제안(AI)** — 정비 대상 조례를 고르면 OpenAI가 **신구대조표**(어느 조문의 옛 명칭을 무엇으로 바꿀지)를 생성. 책 CoVe 원칙으로 *명칭 치환만·환각 없이*. `.md` 저장 지원
- **CSV 내보내기 · 원문 바로가기**

## 📦 설치

### 방법 A — 실행파일(.exe), Python 불필요
1. (배포된 경우) `법률조례_연결확인기.exe` 를 내려받아 **더블클릭**
2. 첫 실행은 압축 해제로 20~30초 걸립니다(이후 빠름)
3. SmartScreen 경고가 뜨면 **[추가 정보] → [실행]**

### 방법 B — 소스로 실행, Python 3.9+
```bat

cd law_finder

```

## 🔑 환경변수 설정

인증키(OC)는 코드에 넣지 않고 **`.env` 파일**이나 시스템 환경변수로 관리합니다.

```bat
copy .env.example .env       REM 복사 후 .env 안의 값을 본인 키로 변경
```

| 환경변수 | 필수 | 설명 |
|---|---|---|
| `LAW_OC` | 권장 | 법제처 OPEN API 인증키(OC). `.env`에 넣으면 실행 시 자동 입력됨. 안 넣으면 프로그램 화면에서 직접 입력 |
| `OPENAI_API_KEY` | 선택 | OpenAI 키. **개정안 제안 기능**에만 필요. [platform.openai.com](https://platform.openai.com/api-keys) 발급 후 `.env`에 설정 |

- `.env` 는 **`.gitignore`로 제외**되어 GitHub에 올라가지 않습니다.
- 인증키는 화면에 직접 입력해도 됩니다(환경변수는 편의 기능일 뿐, 필수 아님).

### 인증키(OC) 발급 — 무료(신청·승인 필요)
인증키는 **활용신청 후 승인을 받아야** 발급되는 값이며, **임의로 만들 수 없습니다.**
1. [open.law.go.kr](https://open.law.go.kr) 회원가입 / 로그인
2. **[OPEN API → 활용신청]** 에서 사용할 API와 활용사례를 등록해 신청
3. 담당자 **승인(보통 1~2일)** 후 사용 가능
4. 승인된 인증키(OC)는 로그인 후 **‘마이페이지 / 신청내역’** 에서 확인

## 📖 사용법

### 입력
- **법률명** — 직접 입력 후 **[🔎 법령 확인]** 으로 정식명칭을 고르면, 옛 이름까지 자동 인식
- **지자체** — 광역(시·도) 선택 → 시·군·구 자동 채움
- **추가 검색어** — 여러 번 개명된 법의 더 옛 이름·약칭을 직접(쉼표 구분) 보탤 때

### 연결강도 (위가 확실한 연결)
| 표시 | 의미 |
|---|---|
| 🟢 **근거(제1조 위임)** | 조례 제1조(목적)에 그 법령명이 있음 — 그 법의 위임으로 제정 |
| 🟠 **인용(본문)** | 본문 다른 조문에서 그 법을 인용 |
| 🟣 **관련(간접)** | 본문을 확인했으나 법령명이 없음(검색 노이즈) |
| ⚪ **미검증** | 본문을 확인하지 않음(‘검증 상위 N건’ 밖) |

- **인용명칭** 칸에 `⚠ 옛이름`이 뜨면 = **정비(개정) 대상**입니다.
- 행을 **더블클릭**하면 국가법령정보센터 원문이 열립니다.

## 🛠 실행파일(exe) 직접 빌드

```bat
pip install pyinstaller
pyinstaller --onefile  --windowed --name "법률조례_연결확인기" law_ordinance_network.py
pyinstaller --onedir   --windowed --name "법률조례_연결확인기" law_ordinance_network.py
```
`--onefile` 은 단일 exe, `--onedir` 은 폴더형(첫 실행이 더 빠름). 결과물은 `dist\` 에 생성됩니다.

## 📋 조례정비 레이더 기능 (2026.9. 추가)

| 기능 | 사용법 |
|---|---|
| **검토카드** | 조회 후 **[📋 검토카드 등록]** → 조례·조문·인용명칭별 ‘변경사건’ 저장(같은 자료 재조회 시 중복 0건, 법령 버전이 바뀌면 새 사건으로 재검토 연결). **[📋 검토카드 열기]** 에서 담당부서·기한·상태·판단사유·확인자 입력, 변경 이력 자동 기록, CSV·백업 |
| **상태 규칙** | 신규 → 검토 중 → 추가 확인 / 정비 불필요 / 정비 추진 → 완료. ‘완료’·‘정비 불필요’는 판단 사유와 확인자 없이 종결 불가 |
| **서울 일괄 점검** | `서울_일괄점검_실행.bat` 더블클릭 → `점검대상_법령.txt` 의 법령을 서울시·25개 구 자치법규 전체에서 점검, `실측결과_날짜` 폴더에 인용목록(소관부서 포함)·확인필요목록·요약 저장 |
| **품질시험** | `품질시험_실행.bat` → 명칭 혼재·제1조의2 경계·조회 실패·중복 방지·버전 변경·복원·CSV 수식 차단·소관부서·의무 조항 선별 등 22개 시험 |
| **소관부서 필터** | 부서 서무 주임(일명 ‘왕서무’)용. ‘소관부서’ 칸에 부서명을 넣으면 우리 부서 조례만 표시(법제처 자치법규 담당부서 기준, 전부 본문 확인). 검토카드 등록 시 담당부서 자동 입력 |
| **🧩 빠진 조문 점검(AI)** | 법이 지자체(국가기관등 포함)에 ‘하여야 한다’고 정한 조항을 규칙으로 골라낸 뒤, 생성형 AI가 조례 조문과 1:1 대조해 반영/공백/확인 필요 표와 개정 방향 초안 제시(OPENAI_API_KEY 필요) |
| **AI 초안 검증** | 개정안·빠진 조문 점검 결과에 원문에 없는 조문번호가 나오면 ‘확인 필요’로 표시 |

검토카드 자료(`radar.db`)는 기관 PC에만 저장되며 외부로 전송하지 않습니다.
